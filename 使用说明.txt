课程文字稿 · Windows 便携版
版本 1.0.0

把一节课，留成文字。
读取北大教学网课程 → 下载完整视频 → 通义听悟转写 → 保存 Word

开始使用
1. 将压缩包中的整个“课程文字稿”文件夹解压到本机。
2. 双击“课程文字稿.exe”。本版已带齐 Python 和视频处理组件。
3. 点击“账号与自动登录”，保存北大统一认证和听悟账号。
4. 点击“读取 / 刷新课程”，选择课程和一节回放。
5. 点击“下载并转写”，等待 Word 文字稿保存。

使用其他来源
“输入回放网址”：粘贴教学网某一节课程的完整回放网址。
“转写已有视频”：选择本机已下载的完整课程视频。

运行方式
默认勾选“无窗口后台运行”。常规处理时浏览器保持无窗口。
遇到验证码或本人确认步骤时，按工具提示点击“显示浏览器”。
完成验证后工具自动继续，打开的窗口也可点击“收起浏览器”最小化。
需要直接查看网页时，可在启动任务前关闭后台选项。

课程与回放
默认显示本学期，也可切换其他学期。
“课堂实录尚未开放”和“暂无回放”的课程会显示提示并禁用下载。
听悟接收完整视频，使用本人网页账号的转写服务。
听悟处理时间及可用额度以网页显示为准。

保存位置
output：课程视频、Word 文字稿和处理结果。
data：本机浏览器登录状态、选项及运行记录。
密码：当前 Windows 用户的凭据管理器。
视频和 Word 文件可在界面点击“打开输出文件夹”查看。

运行条件
Windows 10/11，64 位；已安装 Microsoft Edge 或 Google Chrome。
网络能够访问北大教学网和通义听悟，并留有视频下载空间。
请保留 exe 旁的 _internal 文件夹，它包含程序运行组件。

迁移或分享
发行压缩包仅包含程序组件与说明。
在新位置或另一台电脑首次使用时，请在工具中保存本人账号。
本机使用产生的 data、output 文件夹由当前用户管理。

遇到问题
先按界面提示处理，也可停止后重新读取课程。
已下载的完整视频可以从“转写已有视频”继续。
运行记录位于 data/last-run.log，启动记录位于 data/startup-error.log。
随包的“第三方许可”文件夹保存组件说明和许可文本。

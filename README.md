# 提取北大课程回放文字稿

一个便捷的把北大教学网回放通过通义听悟转写成文字稿的小工具。

北大教学网课程回放 → 下载完整视频 → 将视频上传通义听悟网页转写 → 保存 Word。

## Windows 应用版

本机入口为 `课程文字稿.exe`，双击直接启动，继续使用同目录的现有账号设置和输出文件。程序组件位于 `_internal`，请与 exe 一同保留。

便携发行包位于 `release/课程文字稿_1.0.0_Windows_x64.zip`。将里面整个“课程文字稿”文件夹解压后，双击其中的 exe 即可；已包含 Python、浏览器控制组件、FFmpeg 和 FFprobe，使用电脑已安装的 Edge 或 Chrome。发行包仅包含程序和说明，用户数据在使用后另行生成。

开发打包：安装 `build-requirements.txt` 后运行 `python build_release.py`。打包产物可通过 `课程文字稿.exe --self-check 检查结果.json` 执行本地合成视频下载、无窗口浏览器及界面检查。

## 上传 GitHub

源码仓库保留根目录的 Python 源码和测试、`requirements.txt`、`build-requirements.txt`、`course_transcript.spec`、`start.cmd`、`README.md`、`使用说明.txt`、`assets/`、`.gitignore` 和 `.gitattributes`。

`.gitignore` 已排除本机账号与登录状态所在的 `data/`、课程视频与文字稿所在的 `output/`、私有调试材料 `.private/`，以及虚拟环境、日志、缓存、运行组件和打包产物。图标和打包配置保留在仓库，便于重新构建应用。

便携版压缩包适合通过 GitHub Releases 提供下载。发布时使用 `release/课程文字稿_1.0.0_Windows_x64.zip`，该发行包由打包脚本按程序文件清单生成。已被 Git 跟踪的文件需要另外从索引移除，添加忽略规则后才会按预期保持本地。

## 使用

1. 在 Windows 文件管理器中双击 `start.cmd`。首次启动会安装运行组件。
2. 可点击右上角“账号与自动登录”，分别保存北大统一身份认证和听悟账号，启用自动登录。
3. 在“选择课程回放”中点击“读取 / 刷新课程”。工具读取该账号的课程，默认显示本学期；选择课程后会读取对应回放，按日期从新到旧显示课次、录制时间和教师。选中一节，点击“下载并转写”。也可切换学期，或使用“输入回放网址”入口。
4. 工具下载完整回放，检查画面和声音轨道，将完整视频直接上传给听悟。发现多路媒体时，可以在工具中选择包含教师声音和画面的回放流。
5. 听悟同样优先复用登录状态；网站提供密码登录时，尝试保存的账号密码。短信、扫码、首次服务协议和验证码由本人处理，完成后自动继续。
6. 工具尝试自动上传、打开本课记录、导出 Word；网页操作有变化时，会提示在听悟中完成相应步骤，随后接收 Word 下载并保存。

已下载的视频也可通过“转写已有视频”继续处理。此入口会重新提交视频转写任务；已有听悟任务可直接在听悟网页继续导出。每次上传的视频使用本次任务的唯一文件名，原有视频会保留。

默认勾选“无窗口后台运行”。读取课程、登录、下载和转写使用不创建可见窗口的浏览器。需要本人验证时，工具暂停并启用“显示浏览器”；本人点击后重新加载当前网页，保留登录 Cookie 和标签页会话状态，随后继续处理。打开后的验证窗口可通过“收起浏览器”最小化。关闭后台选项后，下次操作使用普通浏览器窗口。

课程未开放“课堂实录”时，显示“尚未开放”；已开放但没有可观看回放时，显示“暂无回放”。这两种状态都会清空上一门课程的回放选择并禁用下载。页面加载失败会显示读取失败，可刷新重试。

开始下载时会重新读取所选回放的播放链接，续用当前账号的观看权限。课程和带签名的回放链接保留在运行内存中，列表按需刷新；配置文件只保存自动登录和后台运行选项。

## 文件位置

- `output/课程名_时间_编号/`：完整回放视频、Word 文件和任务结果。旧任务生成的音频文件仍保留在原任务文件夹。
- `data/browser/`：本工具独立浏览器的登录状态，与日常浏览器和 Codex 旁边的浏览器分别保存。
- `data/last-run.log`：最近运行记录；出现启动问题时还可查看 `data/startup-error.log` 和 `data/app-error.log`。

账号密码通过“账号与自动登录”窗口输入。密码保存在当前 Windows 用户的凭据管理器中，同一台电脑上重启工具后仍可使用；项目配置文件和运行日志不保存密码。配置文件保存自动登录和后台运行选项。课程访问使用本人登录权限，带签名的网址在错误提示中会被隐藏。

保存后密码输入框会清空，留空保存可保留同一账号的原密码。切换账号时需输入对应的新密码。“删除保存项”只删除本工具的账号凭据，当前网页的登录状态仍可使用。

自动填入密码限定在北大统一身份认证和听悟/阿里云官方登录页面；每次任务对每个网站最多自动提交一次，登录错误时交由本人检查。验证码、扫码、短信和手机令牌仍按网站流程处理。密码登录方式是否可用，以网站实际提供的入口为准。

听悟首页和登录面板加载时，工具会等待登录入口并重试打开，随后进入账号密码登录流程。运行提示会区分首页加载超时、尚未保存账号、密码表单未识别和需要本人验证等情况。

视频上传会依次打开“上传音视频”和“上传本地音视频文件”，等待设置弹窗中的文件输入框出现，再选择完整视频。上传期间保持当前弹窗，等记录生成后进入本次课堂的结果页。

## 运行条件

- Windows、Python 3.11 或更高版本、Microsoft Edge（也可使用 Chrome）。
- FFmpeg 和 FFprobe 已加入 PATH，或将 `ffmpeg.exe`、`ffprobe.exe` 放入 `bin/` 文件夹。
- 网络能正常访问教学网、统一身份认证、课程媒体服务器和通义听悟。
- 预留完整回放视频所需的磁盘空间。

本工具使用听悟网页账号，额度和转写等待时间以网页实际提示为准。

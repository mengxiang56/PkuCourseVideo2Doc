# 提取北大课程回放文字稿

读取北京大学教学网的课程与回放，下载完整课堂视频，通过通义听悟网页账号转写，并保存 Word 文字稿。

**选择课程 → 选择回放 → 下载完整视频 → 听悟转写 → 导出 Word**

## 功能

- **按课程选择回放**：读取账号课程，默认显示本学期，支持切换学期；回放列表展示课次、录制时间和教师。
- **支持三种来源**：选择课程回放、输入回放网址，或转写本机已有视频。
- **上传完整视频**：检查画面和声音轨道后，将完整视频交给听悟处理。
- **复用账号与登录状态**：支持保存北大统一认证和听悟账号，在网站提供密码登录时自动填写。
- **无窗口后台运行**：常规处理使用无窗口浏览器，需要本人验证时提供打开浏览器的入口。
- **接收 Word 文字稿**：尝试自动上传与导出，收到并校验 Word 文件后显示完成。
- **处理空回放状态**：区分“课堂实录未开放”“暂无回放”和读取失败，清空旧选择并按状态控制下载按钮。

## 下载与使用

### Windows 便携版

在本仓库右侧的 **Releases** 中，下载版本对应的 `课程文字稿_版本号_Windows_x64.zip`。

1. 将 ZIP 中整个“课程文字稿”文件夹解压到本机。
2. 双击 **课程文字稿.exe** 启动。
3. 点击“账号与自动登录”，保存北大统一认证和通义听悟账号。
4. 点击“读取 / 刷新课程”，选择课程，再选择一节回放。
5. 点击“下载并转写”，等待界面提示完成。
6. 点击“打开输出文件夹”，查看完整视频和 Word 文字稿。

便携版包含 Python、浏览器控制组件、FFmpeg 和 FFprobe，使用电脑已安装的 Edge 或 Chrome。请将 exe 与旁边的 `_internal` 文件夹一同保留。

### 运行条件

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11，64 位 |
| 浏览器 | Microsoft Edge 或 Google Chrome |
| 教学网账号 | 具备所选课程的回放观看权限 |
| 转写账号 | 可用的通义听悟网页账号 |
| 网络与空间 | 能访问教学网和听悟，并有足够空间保存完整视频 |

### 其他使用方式

| 入口 | 使用场景 |
| --- | --- |
| 选择课程回放 | 从账号课程中选择某一节课 |
| 输入回放网址 | 已有某一节课的完整教学网回放链接 |
| 转写已有视频 | 本机已经保存了完整课堂视频 |

“转写已有视频”会提交新的听悟转写任务。已经提交到听悟的任务，可以在听悟网页中继续处理和导出。

### 后台运行与本人验证

默认启用“无窗口后台运行”。需要验证码、扫码、短信、二次验证或本人确认协议时，工具会提示操作；点击“显示浏览器”后完成相应步骤，工具会继续检查状态并处理任务。

打开的验证窗口可通过“收起浏览器”最小化。需要直接查看网页时，可在启动任务前关闭后台选项。

转写耗时与可用额度以听悟网页为准。教学网和听悟页面流程发生变化时，工具会保留人工继续操作的入口。

## 文件与账号

程序在所在目录保存以下内容：

```text
output/
└─ 课程名_时间_编号/
   ├─ 完整课堂视频
   ├─ 课堂文字记录.docx
   └─ task.json

data/
├─ browser/          浏览器登录状态
├─ settings.json     自动登录与后台运行选项
├─ last-run.log      运行记录
├─ app-error.log     界面运行错误记录
└─ startup-error.log 启动错误记录
```

- 保存的账号密码由当前 Windows 用户的**凭据管理器**管理。
- 配置文件只保存自动登录和后台运行选项；浏览器会话保存在本机 `data/browser/` 中。
- 自动填写凭据限定在北大统一认证与听悟 / 阿里云官方登录页面。
- 每次任务对每个网站最多自动提交一次登录，验证码等本人验证步骤按网站流程完成。
- `.gitignore` 已排除登录状态、私有调试材料、课程视频和文字稿。

## 从源码运行

需要 Python 3.11 或更高版本，以及已安装的 Edge 或 Chrome。

准备 FFmpeg 和 FFprobe：将 `ffmpeg.exe`、`ffprobe.exe` 放入项目的 `bin/` 文件夹，或将它们加入系统 `PATH`。

在 Windows 文件管理器中双击 `start.cmd`，首次启动会创建虚拟环境并安装依赖。

也可以在项目目录的 PowerShell 中手动运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

## 开发与打包

### 项目结构

| 文件 | 用途 |
| --- | --- |
| `app.py` / `app_entry.py` | 桌面界面与 Windows 应用入口 |
| `engine.py` | 登录、下载、上传、转写与导出流程 |
| `catalog.py` | 课程与回放列表读取 |
| `core.py` | 视频下载、轨道检查及 Word 校验 |
| `auth.py` / `credentials.py` | 登录表单处理与 Windows 凭据管理 |
| `managed_browser.py` | 无窗口浏览器与本人验证接续 |
| `runtime_paths.py` / `settings.py` | 运行路径与本机选项 |
| `build_release.py` / `course_transcript.spec` | Windows 程序与便携包构建 |
| `test_*.py` | 回归测试 |

### 运行测试

安装运行依赖后，在项目根目录执行：

```powershell
New-Item -ItemType Directory -Force .private | Out-Null
.\.venv\Scripts\python.exe -m unittest discover -p "test_*.py" -v
```

测试覆盖课程与回放解析、空状态、登录域名限制、凭据错误信息隐藏、无窗口启动、验证接续、完整视频上传、本机加密 HLS 下载和 Word 文件校验。浏览器测试使用本机 Edge 与测试页面，媒体测试使用本机临时服务和合成视频。

Windows 凭据管理器读写测试默认跳过。需要运行时设置 `RUN_WINDOWS_VAULT_TEST=1`，测试会创建、更新并删除独立的虚构凭据。

### 构建 Windows 便携版

打包时需要将 FFmpeg 和 FFprobe 加入 `PATH`。

```powershell
.\.venv\Scripts\python.exe -m pip install -r build-requirements.txt
.\.venv\Scripts\python.exe build_release.py
```

构建结果：

```text
release/
├─ 课程文字稿/
│  ├─ 课程文字稿.exe
│  ├─ _internal/
│  ├─ 使用说明.txt
│  └─ 第三方许可/
├─ 课程文字稿_1.0.0_Windows_x64.zip
└─ 课程文字稿_1.0.0_Windows_x64.zip.sha256
```

脚本还会在项目根目录生成应用入口及运行组件。发行 ZIP 按程序文件清单生成，包含运行组件和许可说明；账号、浏览器会话、视频和文字稿保留在各自的本机数据目录。

可使用打包后的程序执行离线检查：

```powershell
& ".\release\课程文字稿\课程文字稿.exe" --self-check ".\release\检查结果.json"
```

检查内容包括合成视频下载、解密与轨道校验、无窗口浏览器、文件输入、Word 校验和桌面界面初始化。

将构建生成的 ZIP 和对应 `.sha256` 文件作为 GitHub Release 附件上传，即可提供便携版下载。
